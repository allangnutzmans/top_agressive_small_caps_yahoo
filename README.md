# Top Aggressive Small Caps Yahoo

## Description

This is a Python-based exploratory project focused on identifying and analyzing small-cap stocks using data from Yahoo Finance. The goal is to gain insights into high-potential aggressive small-cap investments through data retrieval, analysis, and visualization.

## Features

- 🔍 Fetch small-cap stock data directly from Yahoo Finance  
- 📊 Analyze stock performance using multiple financial metrics  
- 📈 Generate insights and visualizations to support decision-making  

## Installation

To set up the project locally:

1. Clone the repository:

    ```bash
    git clone https://github.com/allangnutzmans/top_agressive_small_caps_yahoo.git
    ```

2. Navigate into the project directory:

    ```bash
    cd top_agressive_small_caps_yahoo
    ```

3. Install the required Python dependencies:

    ```bash
    pip install -r requirements.txt
    ```

## Usage

To run the analysis:

```bash
python main.py

```
Follow the prompts in the terminal or customize the script to suit your analysis preferences.
